# ALLBLACK G10 — Mídia Kit

Landing page / mídia kit de João Pedro (@allblack_g10), criador automotivo com o Civic G10.

Site estático: abra `index.html` ou publique a pasta raiz em qualquer hospedagem estática (GitHub Pages, Vercel, Netlify).

## Estrutura

- `index.html` — página principal
- `support.js`, `image-slot.js` — runtime da página (carrega React/Babel via unpkg)
- `_ds/` — estilos do design system
- `assets/` — imagens (hero, cases, stories, logos de marcas)

> Precisa de internet para carregar React, fontes do Google e ícones Phosphor via CDN.
